# Meal App

I developed this Android meal application using **Kotlin** and **Jetpack Compose** as part of my Mobile Application Development coursework.

The app allows users to search for meals using ingredients or meal names, retrieve meal information from **TheMealDB API**, and save meal data locally using a Room database.

## Features

- Search for meals by ingredient
- Search for meals by name
- Retrieve meal information from TheMealDB API
- Display meal names and images
- Save retrieved meals to a local database
- Search saved meals by name or ingredient
- Store meal ingredients, measurements and other information
- Scrollable search results
- Android back-button navigation

## Technologies

- **Kotlin**
- **Android**
- **Jetpack Compose**
- **Material 3**
- **Room Database**
- **TheMealDB API**
- **Android Studio**

## How to Run

1. Open the project in **Android Studio**.
2. Allow Gradle to synchronise.
3. Start an Android emulator or connect an Android device.
4. Run the application.

An internet connection is required for retrieving meal information from TheMealDB API.
